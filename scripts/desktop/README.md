# Desktop-скрипты

Каталог `scripts/desktop/` пуст: DE-скрипты (KDE Plasma, i3wm, Hyprland) для Ubuntu-редакций
переехали в `scripts/legacy/desktop/` вместе с конфигами.

Основная линия (Arch Linux + KDE Plasma 6) настраивает окружение внутри профиля
`archiso-vibelinux/` (`airootfs/root/customize_airootfs.sh`), поэтому отдельные
desktop-скрипты ей не нужны.
